# Tennis Scoreboard

Веб-приложение для управления теннисными матчами, ведения текущего счёта и просмотра истории завершённых встреч.

## Технологический стек

* **Java 21**
* **Spring Boot** (Spring Web, Spring Data JPA, Bean Validation)
* **PostgreSQL**
* **MapStruct** — маппинг сущностей и DTO
* **Docker** — запуск базы данных и окружения
* **JUnit 5 (Jupiter), Mockito, MockMvc (`@WebMvcTest`)** — тестирование веб-слоя и логики
* **Maven** — сборка проекта

## Основные возможности и API

### Игроки (`/players`)
* `POST /players` — регистрация нового игрока (валидация длины имени от 2 до 30 символов, запрет спецсимволов).
* `GET /players` — получение списка игроков с поддержкой пагинации (`Pageable`).

### Матчи (`/matches`)
* `POST /matches` — создание нового матча по именам двух игроков (проверка, что имена игроков не совпадают с учётом регистра и пробелов, поиск игроков).
* `POST /matches/{uuid}/point` — начисление очка игроку в активном матче и возврат актуального счёта.
* `GET /matches` — получение списка завершённых матчей с опциональной фильтрацией по `player_name` и пагинацией (`Pageable`).
* `GET /matches/{uuid}` — получение информации и текущего счёта конкретного матча по `UUID`.
